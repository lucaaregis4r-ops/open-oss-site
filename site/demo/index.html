LEVE SUA INSTALAÇÃO

Publique onde sua equipe trabalha.

O OSS é open source. Rode localmente, hospede no seu servidor ou use uma plataforma que aceite containers.

01⌘

Executar localmente

Baixe o código, instale o Node.js e inicie o OSS na sua máquina.

npm install && npm startInstalar Node.js ↗
02▣

Docker e servidor próprio

Suba a plataforma em um servidor com dados persistentes e controle total.

docker compose up -dRecomendado para produção
03↗

Hospedagem gerenciada

Use qualquer plataforma que execute containers e monte volumes persistentes.

Sem integração de um clique nesta versão
Antes de publicar: configure HTTPS, armazenamento persistente, backup, atualização e segredos no ambiente do servidor. Os registros e documentos devem permanecer fora da imagem do container.
